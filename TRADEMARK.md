# Trademarks and naming

Offgrid is an **unofficial, independent fork** of [T3 Code](https://github.com/pingdotgg/t3code).
It is not affiliated with, endorsed by, or maintained by T3 Tools Inc. "T3 Code" and its logos are
trademarks of T3 Tools Inc. Offgrid uses its own name and its own icons, and mentions T3 Code only to
say where the source code comes from.

## Forking Offgrid

The [MIT License](./LICENSE) covers the source code. You are welcome to fork, modify, self-host,
and redistribute it. When you publish a fork:

- Keep the copyright notices in [LICENSE](./LICENSE), as the MIT License requires.
- Give your fork its own name and icons, so nobody mistakes it for Offgrid or for T3 Code.
